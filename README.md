# CoffeeShop
體驗 AI 如何處理「全端（Frontend + Backend + Database）」的連動，我建議我們現在直接開啟一個全新的專案，你可以按照以下步驟跟 Antigravity 的 AI Agent 協同開發：

🛠️ 第一步：準備全新的工作基地
在電腦裡建立一個全新的空資料夾，例如：D:\Antigravity\CoffeeShop。

在 Antigravity 中點選 File -> Open Folder，開啟這個新資料夾。
既然你是專業的，你可以用更精準的架構指令來引導 AI。請直接在右側的 Agent 框裡，複製並輸入以下這段極具專業氛圍的 Prompt：

「我想要開發一個標準的產品管理 Web 系統，請幫我建立一個全端的專案架構。需求如下：

技術棧：後端使用 Node.js (Express)，資料庫預留連結 SQL Server 的模組（先用本地陣列或模擬資料庫建立好架構，並寫好 mssql 的連線設定檔）。前端使用乾淨的 HTML/CSS + JavaScript（可用 Bootstrap 刻畫面）。

功能流程：

登入畫面：需有標準的帳密欄位，檢核通過後進入主系統。

功能選單：進系統後可選擇『產品管理』功能。

增刪改查 (CRUD)：顯示產品列表，並有『新增產品』按鈕。

欄位檢核邏輯：

新增/修改產品時，必須檢核：『產品編號』不可重複且必填、『產品名稱』長度需大於2個字、『價格』必須大於0。

檢核無誤後，呼叫後端 API 進行存檔動作。

請先幫我規劃完整的檔案結構，並逐步幫我把程式碼與路由（API Routes）建立起來。」
